
# California Housing Price Prediction

## Project Overview

This project focuses on predicting house prices in California using machine learning regression techniques. It explores the relationship between housing features and median house values to build predictive models.

## Dataset

The project uses the California Housing dataset (`housing.csv`).

The dataset contains information about California housing districts, including features such as median income, housing age, average rooms, population and geographical location.

## Technologies and Libraries

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Methodology

1. Data loading and exploration.
2. Data cleaning and preprocessing.
3. Exploratory Data Analysis (EDA).
4. Feature selection and preparation.
5. Training regression models.
6. Model evaluation and comparison.

## Models

- Ridge Regression
- Lasso Regression
