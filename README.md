# Hands-on AI/ML internship projects exploring predictive modeling, regression, NLP, data preprocessing, model evaluation, and Python-based machine learning workflows.

## Repository Organisation and Submission Guidelines

All completed projects are maintained within this GitHub repository and organised into dedicated directories.

### Project Structure

- `project-1-california-housing/` – California Housing Price Prediction.
- `project-2-sentiment-analysis/` – Sentiment Analysis using Natural Language Processing (NLP).

Each project contains its relevant Jupyter Notebooks, datasets, documentation and dependency requirements.

### Development and Reproducibility

- Projects are updated progressively as development continues.
- Dependencies are documented using `requirements.txt` or an equivalent environment configuration file.
- Jupyter Notebooks and Python scripts should run cleanly from beginning to end.
- Project documentation provides information about the datasets, methodologies, tools and results.
