# Datheon AI/ML Internship Projects

Hands-on Artificial Intelligence and Machine Learning projects focused on predictive modelling, data analysis, Natural Language Processing (NLP), and practical machine learning workflows using Python.

## About This Repository

Welcome to my AI/ML internship project repository.

This repository documents my practical learning and development throughout the Datheon AI/ML Internship. It contains projects designed to strengthen my understanding of machine learning concepts, data preprocessing, exploratory data analysis, model development, evaluation, and real-world problem-solving.

The goal is not just to build models, but to understand the processes behind them, experiment with different approaches, evaluate their performance, and develop reproducible machine learning solutions.

## Projects

### Project 1: California Housing Price Prediction

**Focus:** Predictive Modelling | Regression | Supervised Learning

This project explores the use of machine learning regression algorithms to predict median house values in California based on housing and demographic features.

Key areas covered:
- Data loading and exploration.
- Data cleaning and preprocessing.
- Exploratory Data Analysis (EDA).
- Feature preparation.
- Ridge Regression.
- Lasso Regression.
- Model evaluation and comparison.

**Project directory:** `project-1-california-housing/`

### Project 2: Sentiment Analysis Using NLP

**Focus:** Natural Language Processing | Text Classification | Supervised Learning

This project focuses on developing a machine learning system that classifies movie reviews as positive or negative.

It explores how raw text can be cleaned, transformed into numerical representations, and used to train classification models.

Key areas covered:
- Text preprocessing and cleaning.
- Tokenization.
- Stopword removal.
- Lemmatization.
- TF-IDF feature extraction.
- Multinomial Naive Bayes.
- Logistic Regression.
- Model evaluation and comparison.
- Custom sentiment prediction.

The project also includes a larger benchmark experiment using the IMDb Large Movie Review Dataset.

**Project directory:** `project-2-sentiment-analysis/`

## Repository Organisation and Reproducibility

Each project is maintained in its own dedicated directory containing its relevant notebooks, datasets, documentation, and dependency requirements where applicable.

Development follows these principles:

- Projects are updated progressively as development continues.
- Dependencies are documented using `requirements.txt` or an equivalent environment configuration.
- Notebooks should run sequentially from beginning to end.
- Dataset sources and preprocessing methods are documented.
- Model performance and experimental findings are reported in the relevant project documentation.
